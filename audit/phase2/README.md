# Phase 2 evidence

The prospective amendment is commit `9924f5e`. The user subsequently authorized
completing all gates without separate intermediate approval messages.

`GATE_REPORT.md` records observed results and remaining verification limits.
Each `*-before.txt` / `*-after.txt` records the exact pytest command, output and
exit status. These are actual executions, including the expected failing tests.

The inference commands use the repository venv with `PYTHONPATH=''`. New rows go
to `results/raw/qwen_v2.jsonl`; the matched-context B2C ablation is separate at
`results/raw/qwen_v2_ablation.jsonl`. Never use either source archive as an output.

The fixed batch configs are `configs/v2_gate.yaml` (160),
`configs/v2_remaining.yaml` (640), and `configs/v2_ablation.yaml` (200).
`scripts/run_v2.py` verifies the installed model/server identity before generation,
configures only the new cache namespace, and records provenance and wall time.
Batch manifests are immutable: a repeated invocation writes a separate record and
preserves the first observed batch timing. Row wall times retain per-row measurements. Historical request latency and batch wall time are different metrics.

`scripts/assemble_v2.py` reuses controls only after exact deterministic execution
comparison with a client that raises if a model is requested. All reused rows keep
their v1 prompt-version label and carry explicit source IDs and hashes.

Primary figures and hypothesis tables are generated by the unchanged
`analysis/make_figures.py` in a new working directory under `results/v2`.
Additional costs, named outcomes and task-cluster intervals are produced by
`analysis/derive.py`. `analysis/compare_versions.py` writes descriptive version
differences and secondary ablation comparisons. No equivalence conclusion follows
merely from an interval containing zero. Ablation intervals use the same alpha as
the primary helper but do not establish familywise control over every exploratory
comparison.

`scripts/verify_phase2.py` checks archived hashes, frozen design, exact new IDs,
validity, reconstruction and reuse provenance without inference.

Phase 1 evidence under `audit/` retains its original paths and source assumptions
as a historical record. Its scripts were executed before the format repair; use
that code snapshot for historical replication rather than treating them as current
v2 analysis entry points.
